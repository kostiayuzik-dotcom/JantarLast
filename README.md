# Jantar Kadry — Android WebView demo

A simple Android application that opens the employee portal in a WebView.
Each employee signs in on the employer's portal using their own credentials.
The app does not collect or store passwords.

## Build
Requires JDK 17, Android SDK 36, and Gradle 8.11.1.
Run `gradle assembleDebug` from this directory after installing Android SDK components.

This is a demo. Obtain employer/vendor permission before distributing it or using company branding.
